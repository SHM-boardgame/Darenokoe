# お題テーマサイト 仕様書

## 概要

本システムは、俳句・川柳ゲーム向けの「お題テーマ」を検索・閲覧するスマートフォン向けWebサイトである。

利用者は、

```
コミュニティ
→ カテゴリ
→ テーマ
```

の順に辿り、

**上五・中七のお題を数秒で見つけられること**を目的とする。

ゲームプレイ中に利用することを前提とし、
装飾よりも

- 検索性
- 視認性
- 操作性
- 表示速度

を最優先とする。

---

# 基本方針

- モバイルファースト
- 片手操作
- 高速表示
- シンプルUI
- Material Design風
- 白基調
- ボードゲーム中でも使いやすいUI

---

# トップページについて

本サイトは印刷物にQRコードを掲載する。

**QRコードは変更できないため、トップページ(URL)は永続的に固定する。**

今後の機能追加があっても、

- URLは変更しない
- トップページは削除しない
- レイアウトを大きく変更しない

ことを前提とする。

機能追加は

- 機能カード
- メニュー
- ショートカット

を追加する形で対応する。

# データ管理

テーマデータは

```
Community-topics.md
```

のみを編集して管理する。

テーマをソースコードへ直接記述してはならない。

Markdownを編集するだけで

- テーマ追加
- テーマ削除
- カテゴリ追加
- カテゴリ削除

できる構造とする。

---

# Community-topics.md 構造

Community-topics.md は以下の階層構造とする。

```
# 大分類

## 中分類

### コミュニティ

#### 上五

- テーマ
- テーマ
- テーマ

#### 中七

- テーマ
- テーマ
- テーマ
```

例

```markdown
# 家族

## 家族

### 親子

#### 上五

- キッチン
- 幼稚園
- ランドセル

#### 中七

- 送り迎えで
- 手をつないで
- 一緒に遊ぶ
```

---

## Markdownルール

必ず以下の構造に従うこと。

```
#
大分類

##
中分類

###
コミュニティ

####
上五

####
中七
```

#### 上五

- 名詞・物・場所・人・状態など
- 4〜6モーラ程度
- 15件以上推奨

#### 中七

- 動作・出来事・ベクトル・行動など
- 6〜8モーラ程度
- 15件以上推奨

---

## パースルール

Markdownの

```
###
```

を1ページとして扱う。

つまり

```
### 親子
```

なら

```
親子ページ
```

になる。

その中の

```
#### 上五
```

配下は

上五一覧

```
#### 中七
```

配下は

中七一覧

として読み込む。

# テーマID

各テーマには表示名とは別に

**一意のID**

を生成する。

表示名をキーにしてはならない。

例

```json
{
  "id": "family-parent-kitchen",
  "text": "キッチン",
  "type": "kami5"
}
```

または

```json
{
  "id": "work-company-team-meeting-room",
  "text": "会議室",
  "type": "kami5"
}
```

---

## ID命名規則

```
大分類-中分類-コミュニティ-テーマ
```

英数字とハイフンのみ。

例

```
family-parent-kitchen

family-parent-kindergarten

work-company-team-meeting-room
```

IDは

- お気に入り
- 将来の人気順
- 将来の履歴

など全てで利用する。

# 開発方針

- UIはシンプルさを最優先する。
- ゲーム中でも数秒で目的のテーマへ到達できることを目標とする。
- Community-topics.md を唯一のテーマデータソースとし、Markdownの構造に従って自動的にページを生成する。
- UI・データ構造・コンポーネントは保守性・拡張性を考慮して設計する。
- トップページのURLは永続的に維持し、印刷済みQRコードから継続してアクセスできることを保証する。
