# 「閑さや 岩にしみ入る 誰の声」用コミュニティツリー
## 概要
- このファイルは、お題作成サイトで使用するコミュニティツリーを定義します。
- ユーザーは「あなたたちは、どのような集まりですか？」という質問に対して、このツリーからコミュニティを選択します。
### 設計ルール
- 中間ノードは分類・ジャンルを表します。
- 末端ノードは実際のコミュニティ名称を表します。
- タグは `Community-tags.md` で管理します。
