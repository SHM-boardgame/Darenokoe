# 「閑さや 岩にしみ入る 誰の声」用トピック一覧
## 概要
- 各コミュニティに属する「お題の種」を管理する。
	- テーマは共通体験・専門用語・あるある・文化・作品名などを登録している
	- 1カテゴリにつき10~20個程度のテーマを登録している
- ここに登録される単語・短文・固有名詞は、ユーザーがお題を考える際のヒントとして表示される
- 検索用途ではなく、一覧表示用途として利用する
- ユーザーは一覧から気になったトピックを選び、そのトピックを題材として上五・中七を考える
